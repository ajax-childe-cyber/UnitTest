Консольный калькулятор: пользователь вводит оператор (`+`, `-`, `*`, `/`) и два числа, программа выводит результат. Обрабатываются деление на ноль и неверный знак операции.

Код разделён на модули, вычисления покрыты модульными тестами

Структура репозитория

```
UnitTest.sln            - решение Visual Studio
Console/                - проект приложения
  Console.cpp           - точка входа: ввод, вызов вычислений, вывод
  calculation.h / .cpp  - вычисления (сложение, вычитание, умножение, деление, Calculate)
  input.h / .cpp        - ввод данных из консоли
  output.h / .cpp       - вывод результата и сообщений об ошибках
ObjectTesting/          - проект модульных тестов (Microsoft Unit Tests)
  ObjectTesting.cpp     - 23 теста для модуля calculation
docs/
  test-plan.md          - план тестирования и соответствие тестов сценариям
  test-explorer.png     - скриншот результата запуска тестов
.gitignore              - исключает служебные файлы Visual Studio
```

> Проект приложения называется `Console`, проект тестов `ObjectTesting`.

Модули

| Модуль | Код |
|---|---|
| `calculation` | арифметические функции `Clojenie`, `Vichitanie`, `Umnojenie`, `Delenie` и функция `Calculate(op, a, b, result)`, выбирающая операцию по знаку |
| `input` | `ReadOperator()`, `ReadNumber(prompt)` - чтение данных пользователя |
| `output` | `PrintResult(status, result)` - печать ответа или сообщения об ошибке |
| `Console.cpp` | сценарий запуска: прочитать данные, вызвать `Calculate`, вывести результат |

Функция `Calculate` возвращает код:

| Код | Значение |
|---|---|
| `0` | операция выполнена, результат записан в `result` |
| `1` | деление на ноль |
| `2` | неверный знак операции |

## Требования

- Windows
- Visual Studio 2022 или новее 
- Компонент для тестов C++ 

Пример работы:

```
Введите оператор: /
Введите первое число: 6
Введите второе число: 3
Ответ: 2
```

Запуск тестов через Test Explorer

1. Откройте решение и выполните **Сборка → Пересобрать решение**.
2. Откройте **Тест → Обозреватель тестов** (Test Explorer).
3. Нажмите **Выполнить все тесты**.
4. Ожидаемый результат: **23 теста пройдено, 0 не пройдено**, предупреждений 0.

Тесты разделены на три группы:

- `CalculatePositiveTests` - 9 тестов (корректные данные)
- `CalculateBoundaryTests` - 8 тестов (граничные значения)
- `CalculateNegativeTests` - 6 тестов (ошибочные условия)
